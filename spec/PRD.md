# 동물 테스트 위장 정신건강 선별 PWA (animal-test)

## 1. 개요
겉으로는 가벼운 "나와 닮은 동물 테스트"처럼 보이지만, 실제로는 PHQ-9(우울 선별 척도)를 그대로 실시하고 점수 구간에 맞는 상담기관을 연결해주는 모바일 웹앱(PWA)이다.

- 출발점: 문서 「위장 UI의 선한 활용 방안」(2026-09-29, 작성자 송강)의 사례 4 "정신건강·중독 자가진단"
- 윤리 기준(문서 원칙): 이 앱은 아무도 속이지 않는다. 낙인에 대한 부담만 덜어준다. 본인 기기에서 본인 데이터만 다루고, 연결하는 곳은 공인 기관뿐이다.
- 현재 단계: **구현 + 배포(테스트용)**. 실제 사용자 공개 전이며 사용자 수 데이터는 없다.
- 배포 URL: https://parkjihee-jenna.github.io/animal-test/
- 저장소: https://github.com/ParkJihee-jenna/animal-test

## 2. 문제와 사용자
- 문제: 우울 자가진단을 하고 싶어도 "정신건강 테스트"를 하는 모습이 주변에 보이는 것 자체가 부담이다(낙인).
- 대상: 주변 시선을 신경 쓰는 청소년·대학생·직장인
- 해결: 평범한 심리테스트 외관 + 검증된 척도 + 결과 화면에서 조용히 상담기관 안내

## 3. 범위
### 포함 (MVP)
- PHQ-9 9문항, 4점 척도(0~3), 총점 0~27
- 점수 구간별 동물 결과 5종
- 9번 문항에 1점 이상 응답하면 긴급 배너 표시
- 빠른 탈출(✕ 버튼 또는 Esc)
- PWA 설치와 오프라인 캐시

### 비목표
- 서버, 계정, 응답 저장(localStorage 포함), 분석·트래킹 스크립트 — **절대 넣지 않는다**
- 진단 기능, 단정형 결과 문구
- 도박(1336)·음주 척도 — 2차 범위 후보
- 직접 상담 운영

## 4. 화면 흐름
1. **intro**: 🦦🐱🐼 / 「나와 닮은 동물은?」 / 「최근 2주를 떠올리며 9개 질문에 답해보세요. 1분이면 끝나요.」 / [테스트 시작하기]
2. **question ×9**: 진행 바, `{동물 아이콘} Q{n}` · `{n} / 9`, 리드 문구 「지난 2주 동안 얼마나 자주 있었나요?」, 문항, 선택지 4개. 선택하면 테두리가 강조되고 **250ms 뒤** 자동으로 다음 문항으로 넘어간다. 2번 문항부터 「← 이전 질문」이 보인다.
3. **result**: `body.care`로 배경이 그린으로 전환되고 맨 위로 스크롤된다. 순서는 (긴급 배너) → 동물 카드 → 선별 도구 고지 → 기관 목록 → [처음으로]

## 5. 문항과 채점 규칙
- 선택지와 점수: `전혀 없었다`=0, `며칠 동안 있었다`=1, `일주일 이상 있었다`=2, `거의 매일 있었다`=3
- 총점 = 9문항 점수의 합
- 문항 원문은 `docs/app.js`의 `Q` 배열에 있다. PHQ-9 출처: Kroenke, Spitzer & Williams(2001), Pfizer 무료 사용

> ⚠️ 한국어 문항은 공식 한국어판과 대조하지 않았다. 기억에 의존해 작성했으므로 공개 전에 반드시 표준 번역본과 맞춰야 한다.

| 총점 | 이모지 | 이름 | 밴드 라벨 |
|---|---|---|---|
| 0–4 | 🦦 | 햇살 쬐는 수달 | 최소 수준 |
| 5–9 | 🐱 | 창가의 고양이 | 가벼운 수준 |
| 10–14 | 🐼 | 쉬고 싶은 판다 | 중간 수준 |
| 15–19 | 🦥 | 천천히 가는 나무늘보 | 중간 이상 수준 |
| 20–27 | 🦔 | 웅크린 고슴도치 | 높은 수준 |

- 구간 판정은 `BANDS.find(b => score <= b.max)`로 한다. 각 구간의 max 값은 4/9/14/19/27이다.
- 결과 배지 형식: `마음 건강 {밴드} · {score}/27`
- 긴급 판정: `ans[8] >= 1`(9번 문항). 이 조건이 맞으면 총점과 무관하게 배너를 띄운다. 배너를 누르면 `tel:109`로 전화가 걸린다.
- 기관 섹션 제목: 총점 ≥5이거나 긴급이면 「이야기해볼 곳이 있어요」, 그 외에는 「필요할 때 기억해두세요」. 기관 목록은 항상 보여준다.
- 고지 문구(항상 표시): 「이 결과는 진단이 아니라 PHQ-9 선별 도구 결과예요. 정확한 판단은 전문가와 함께해요. 응답은 어디에도 저장되지 않아요.」

## 7. 안전·프라이버시 요구사항
- 응답은 JS 변수 `ans`(메모리)에만 둔다. 새로고침하면 사라진다.
- 탈출: ✕ 버튼 또는 Esc → `ans=[]` 후 `location.replace('https://www.google.com/search?q=오늘 날씨')`. 뒤로 가기 기록에 남지 않는다.
- 탭 제목과 PWA 이름에는 "동물 테스트"만 쓴다. 정신건강 관련 단어를 노출하지 않는다.
- 외부 링크에는 `rel="noopener noreferrer"`를 붙인다.

> ⚠️ 알려진 한계: 척도 타당성을 지키려고 문항 원문을 바꾸지 않았다. 그래서 질문 화면을 누가 직접 보면 위장이 드러난다(특히 9번 문항). 이 한계는 의도적으로 감수했다.

## 9. 기술 구성
- 정적 HTML/CSS/JS로 만들었고 빌드 단계가 없다. 파일은 `docs/` 아래에 있다: index.html, style.css, app.js, manifest.json, sw.js, icon.svg
- 서비스워커: 캐시 `v1`. 설치할 때 6개 파일을 캐시하고, 요청은 캐시를 먼저 확인한다.
- 배포: GitHub Pages, `main` 브랜치의 `/docs` 폴더(legacy build)
- 로컬 실행: `python3 -m http.server 5173 -d docs`

> ⚠️ 함정 1: `gh` 토큰에 `workflow` scope가 없어서 `.github/workflows` push가 거부됐다. 그래서 Actions 배포 대신 /docs 폴더 배포로 바꿨다.
> ⚠️ 함정 2: 서비스워커가 cache-first 방식이라 수정하고 배포해도 기존 방문자에게는 예전 파일이 보인다. 수정할 때마다 `sw.js`의 `C='v1'` 값을 올려야 한다(현재는 이전 캐시를 삭제하는 로직도 없다).

## 10. 열린 결정
- PHQ-9 공식 한국어판 문구로 교체
- 기관 번호와 URL 검증
- 서비스명: "숨결"은 가칭이다(사용자에게 보이는 이름은 "동물 테스트").
- 2차 척도(도박·음주)를 넣을지 여부
- 실제 상담기관에 피드백 받기
